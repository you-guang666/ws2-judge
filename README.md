# WS₂ Layer Judge

明场显微 RGB 颜色区间快速判定 WS₂ 层数 — SiO₂/Si 衬底机械剥离 WS₂

## Live Demo

👉 **[https://you-guang666.github.io/ws2-judge](https://you-guang666.github.io/ws2-judge)**

## 功能

- 输入显微图像样品区域 RGB 值
- 自动匹配 7 个预设颜色区间（衬底 → 体相 Bulk）
- 输出层数范围、物理厚度、材料物性
- 实时颜色预览 + 参考色卡对比

## 颜色区间

| 颜色 | 层数 | 厚度 |
|------|------|------|
| 淡紫 | 0 (衬底) | 0 nm |
| 蓝青 | 1~2 层 | 0.7~1.4 nm |
| 青绿 | 3~4 层 | 2.1~2.8 nm |
| 浅青 | 5~6 层 | 3.5~4.2 nm |
| 黄绿 | 6~15 层 | 4.2~10.5 nm |
| 橙黄 | 15~30 层 | 10.5~21.0 nm |
| 橙红 | >30 层 (Bulk) | >21.0 nm |
